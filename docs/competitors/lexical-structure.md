# Сравнение лексической структуры C# и Python

## 1. Структурное программирование

### Блоки кода

В Python блоки определяются отступами: лексеру нужно выдаваьб токены NEWLINE, INDENT, DEDENT

Пример блока: 
```
if expr: \n
    <indent>
```

В C# определение блоков происходит по фигурным скобкам `{` `}`; лексер токенизирует их и по ним определяет блоки. Также `;` тоже является токеном и является обязательным.

### Ветвления
Python: `if x: ... elif y: ... else: ...` \
C#: `if (x) {...} else if (y){...} else {...}`

В Python скобки в условиях не требуются, добавочное условие - `elif` - как отдельное ключевое слово. Также в Python `:` является токеном начала блока и обязателен в конструкциях.

### Циклы
Python: \
`for <target> in <expr>:` - универсальная итерация по итерируемым объектам. \
`while <expr>:` — стандартный.

C#: \
for (init; cond; iter) { } - классический C-подобный цикл. Токены: `for`, `(`, `;`, `)`. Цикл похожий на цикл Python: `foreach (type id in expr) { }` \
Также есть `while`, `do-while`

## 2. Средства ввода/вывода и встроенные функции

Python: встроенные функции в виде индентификаторов: `print`, `input`, `len` и т.д.; они не выделяются лексически, так как являются обычными индентификаторами.
```python
import sys # стандартная библиотека импортируется ключевым словом import

print("Hello") # обычный вывод

name = input("Введите ваше имя: ") # чтение ввода с клавиатуры
print(f"Привет, {name}!") # вывод с интерполяцией (интерполяция встроена в лексер/парсер)

length = len(name) # возвращает длину переданной переменной
```

C#: Встроенные функции находятся в пространствах имён. 
```cs
using System; // using - ключевое слово для доступа к библиотекам

string line;
line = Console.ReadLine(); // ввод 
Console.WriteLine(line); // обычный вывод
Console.WriteLine($"Value: {line}"); //вывод с интерполяцией 

length = line.Length // тоже возвращает длину
```
Здесь `Console` и `WriteLine`/`ReadLine` являются инденификаторами, но образуют точечную нотацию, поэтому `.` тоже является токеном.

## 3. Пользовательские функции
### Объявление 
Python:
`def name(params):` + блок \
C#:
`[modifiers] returnType name(params) { }`

В Python отсутствует обязательные типы, поэтому `return` необязателен( его отсутствие => `None`), в то время как в C# либо указывается void или же тип данных, то есть тип возвращаемого значения обязателен

## 4. Встроенные типы: целые, плавающие, строки
### Целые числа
Python: \
`int` (произвольной точности), не требует анализа размера. Литералы в которых может быть представлен:
- десятичный: `42`
- шестнадцатеричный: `0x2A`
- восьмеричный: `0o52`
- двоичный: `0b101010`

С#: \
Большое разнообразие типов целых чисел: `byte`, `short`, `int`, `long`.
Литералы:
- `123`
- `0xFF`
- `0b1010`
Строгая типизация, здесь уже нужно проверять размер, учитывать занковость и переполнение.

### Числа с плавающей запятой
В Python также один тип: `float`, подходит для большинства задач, а в C# уже больше типов: `float`, `double`, `decimal` и уже здесь выбор влияет на точность и поведение. 

### Строки
В обоих языках строки довольно похожи (Unicode, поддерживают конкатенацию, интерполяцию, много похожих методов), но токены разные - `str` в Python и `string` в C#

## 5. Выражения c операторами
### Арифметические операторы
Оба языка имеют набор арифметических операторов, но в Python есть операторы `**` и `//` (возведение в степень и деление нацело)

### Логические операторы
Оба реализуют логические операторы, но в Python они представлены ключевыми словами `and`, `or`, `not`, а в C# - токенами `&&`, `||`, `!`

### Операторы сравнения
Оба имеют стандартный набор операторов сравнения (==, !=, <, >, <=, >=), но в Python также реализованы цепочечные сравнения: `a < b < c`.

## 6. Пользовательские составные типы данных
### Массивы
Python:
В Python `list` динамический, без объявления типов (внутри могут быть данные разных типов); проверяются типы на этапе выполнения

C#:
В C# `Array` строго типизированный, фиксированный по размеру, поэтому типы проверяются на этапе компиляции.

### Структуры (записи)
В Python нет встроенного `struct`, как например в C-подобных языках. Вместо этого пользовательские составные типы создаются через `class` — синтаксис классов динамичен, нет разграничения value/reference. В Python структура — это гибкий объект, часто с динамически добавляемыми полями.

В C# же есть как `class`(reference type), так и `struct` (value type)

Python:
```python
class Name: def __init__(self, x, y): ...
```

```cs
struct Name { [modifiers] type name }
```
