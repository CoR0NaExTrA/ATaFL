## 1. Сравнение числовых типов данных
В Python числовые типы имеют неограниченную точность, поэтому нет большого разнообразия в типах (`int`, `float`). Также есть встроенные комплексные числа (`complex`). Нет типа `decimal`, но можно подключить через модуль.

В С# каждый числовый тип имеет свой диапазон, поэтому существует множество числовых типов (`int`, `long`, `long long`, `float`, `double`, `uint`, `uint8` и т.д.). Встроенного типа комплексных чисел нет, но реализуются через `System.Numerics.Complex`. Однако есть встроенный тип `decimal` для работы с финансами.

## 2. Сравнение арифметических операторов
 
Оба поддерживают базовые операторы: сложения `+`, вычитания `-`, умножения `*`, деления `/` (Python всегда возвращает float; C# — тип зависит от операндов), деление с остатком `%`, унарный плюс/минус `+a`, `-a`. \
Однако в C# нет отдельного оператора возведения в степень и целочисленного деления, как в Python - `**` и `//`. Вместо этого либо использование функции (`Math.Pow(a, b)` вместо `**`) либо результат зависит от операндов (`/` работает как для целых, так и вещественных типов, только для вывода результата с плавающей запятой один или два из операндов должен быть вещественного типа)

## 3. Сравнение приоритетов операций
**Python**

Основные операции (убывание приоритетов):
```py
1. ()	# Скобки
2. **	# Возведение в степень
3. +x, -x, ~x	# Унарные плюс, минус и битовое отрицание
4. *, /, //, %	# Умножение, деление, целочисленное деление, остаток от деления
5. +, -	# Сложение и вычитание
6. <<, >>	# Битовые сдвиги
7. &	# Битовое И
8. ^	# Битовое исключающее ИЛИ (XOR)
9. |	# Битовое ИЛИ
10. ==, !=, >, >=, <, <=, is, is not, in, not in	# Сравнение, проверка идентичности, проверка вхождения
11. not	# Логическое НЕ
12. and	# Логическое И
13. or	# Логическое ИЛИ
```

**C#**
Приоритеты похожи, но есть некоторые расхождения.

В C# после сдвигов идёт операторы сравнения, и только потом операторы битовых операций. Также в конце списка находится тернарный оператор `?:`


## 4. Список лево- и правоассоциативных операторов
**Python** 
Левоассоциативные:
`+`, `-`, `*`, `/`, `//`, `%`, `&`, `|`, `^`, `<`, `<=`, `>`, `>=`, `==`, `!=`, `in`, `is`, `and`, `or`

Правоассоциативные:
`**`, `=`, `+=`, `-=` и другие операторы с присваиванием

**C#**
Левоассоциативные:
`+`, `-`, `*`, `/`, `%`, `<<`, `>>`, `<`, `<=`, `>`, `>=`, `==`, `!=`, `&`, `^`, `|`, `&&`, `||`

Правоассоциативные:
`?:`, `=`, `+=`, `-=`, `*=`, /`=`, `%=` и другие присваивания

## 5. Сравнение встроенных функций для работы с числами
**Python** 

`abs()`; `round()`; `pow()`; `max()`; `min()`; `math.floor()`; `math.ceil()`; `math.sqrt()`; `math.sin()`, `cos()`, `tan()` и т.д.; `math.pi`, `math.e`

**C#**

`Math.Abs()`; `Math.Round()`; `Math.Floor()`;
`Math.Ceiling()`; `Math.Min()`; `Math.Max()`; `Math.Pow()`; `Math.Sqrt()`; `Math.Sin()`, `Cos()`, `Tan()` и т.д.; `Math.PI`, `Math.E`

Ключевые различия: \
В C# нет встроенных функций в сам язык, он централизует всё в `System.Math`, тогда как в Python основные функции встроенные либо доступны в модуле `math`. 

## 6. Прочие особенности синтаксиса выражений
В Python нет встроенного тернарного оператора (вместо этого используется выражение `x if cond else y`), в то время как в C# он есть - `cond ? x : y`

Ещё в Python и C# отличаются в цепочках сравнений: в C# нельзя два оператора сравнения записать для одной переменной (потребуется логический оператор - `(1 < x) && (x < 10)`), тогда как в Python это же выражение можно записать как `1 < x < 10`

Также немного отличается синтаксис явного преобразования типов:
**Python** - `int(x)`, `float(x)`
**C#** - `(int)x`, также можно использовать класс Convert (`Convert.ToInt32(x)`)
