# Сравнение Python и C#

## 1. Синтаксис циклов, ветвлений, блоков кода
### Циклы
И в Python, и в C# есть `while`, `for`, но в C# есть также такие конструкции как `do..while` и foreach

### Ветвления

В обоих языках есть базовые `if`, `else`. \
Отличается промежуточное условие между if и else: **Python** - `elif`(синтаксический сахар), а в C# - `else if` (ещё одно условие вложенное в else). \
В Python нет `switch`, но с Python 3.10 появился прямой аналог switch - `match-case`.

### Блоки кода
В Python блоки кода определяются при помощи отступов, что требует от лексера/парсера отслеживания отступа и генерации спец.токенов(`INDENT`, `DEDENT`). \ 
В C# блоки кода выделяются фигурными скобками и символом `;` между инструкциями и это упрощает парсинг тем, что грамматика чисто контекстно-свободная, можно использовать LL/LR-анализ.

## 2. Базовые типы данных
Python: int, float, bool, str, list, tuple, set, dict, None \
C#: int, long, short, byte, float, double, decimal, bool, string, array, `List<T>`, `HashSet<T>`, `Dictionary<TKey, TValue>`, null

В Python динамическая типизация, определяет типы во время выполнения, что упрощает парсинг, но семантический анализ будет сложнее.
В C# же статистическая типизация, типы известны уже на этапе компиляции и также C# требует проверки типов, но этим облегчает генерацию IR.

## 3. Набор операторов
1. Оба языка поддерживают арифметические операторы: +, -, *, /, %. В Python также есть ** (возведение в степень)
2. Оба языка поддерживают операторы сравнения: == != < > <= >=
    - C#: == сравнивает по значению для примитивов, по ссылке для объектов
    - Python: == сравнивает по значению, is сравнивает идентичность объектов
3. Оба поддерживают логические операторы: &&/and, ||/or, !/not

Python требует больше семантических проверок (например, is vs ==), тогда как C# — больше синтаксических правил.

### Особые операторы
C#:
```cs
as       // безопасное приведение
is        // проверка типа
??        // null-coalescing
?.        // null-conditional
```
Python:
```python
is, is not          # проверка идентичности
in, not in          # проверка принадлежности
```

## 4. Описание пользовательских функций
### Объявление

**C#**:
```cs
public int Add(int a, int b) 
{
    return a + b;
}
```

**Python**:
```python
def add(a, b):
    return a + b
```

**Различия**: \
В Python гибкая сигнатура, поддержка `*args`, `**kwargs`, именованных параметров, что требует более широкой грамматики и семантики.

В C# фиксированная сигнатура, строгая типизация параметров, поддержка `ref`, `out`, `params`.

Python требует динамической обработки аргументов, C# — статической проверки и генерации сигнатур. 

## 5. Описание пользовательских структур
В Python для создания структур данных используются классы (`class`). Нет отдельного понятия "структура" как в C-подобных языках. \
В С# `struct` — value-type, копируется по значению. \
C# различает классы и структуры по семантике (heap vs stack), Python — нет. Это влияет на генерацию IR.

Примеры пользовательских структур:
```python
class Point2D:
    def __init__(self, x, y):
        self.x, self.y = x, y
```

```cs
public struct Point 
{
    public double X, Y;
    public Point(double x, double y) 
    {
        X = x;
        Y = y;
    }
}
```

## 6. Работа с массивами
В C# есть статистические (`T[]`) и динамические (`List<T>`) списки/массивы, тогда как в Python они универсальны/могут содержать любые типы данных (`list`)
В Python есть поддержка отрицательных индексов, а в C# их нет

## 7. Обработка ошибок
Оба языка обрабатывают ошибки через конструкцию try...catch, только в Python вместо catch - except. \
Также оба имеют блок finally и в Python есть дополнительный else блок.
По сути механизмы похожи, различия - в синтаксисе и типизации

## 8. Управление памятью

Оба языка имеют сборщики мусора(автоматическое управление памятью), но также в C# есть механизмы освобождения ресурсов (IDisposable, using). \
В C# value types размещаются на стеке, а reference types размещаются в управляемой куче. Тогда как в Python все объекты размещаются в куче и нет прямого доступа к памяти
