# Семантика типов данных языка программирования Blueprint

## Краткое описание
Язык Blueprint является строго типизированным императивным языком.
Каждая переменная, параметр, литерал и результат выражения имеют конкретный статический тип.

Blueprint поддерживает следующие встроенные типы данных:
|Тип    |Описание                                              |
|-------|------------------------------------------------------|
|number |32-битное целое число (−2 147 483 648 … 2 147 483 647)|
|decimal|Число с плавающей точкой (формат - IEEE 754 binary64) |
|text   |Строка в UTF-8                                        |
|void   |Пустой тип для функций, не возвращающих значения      |

**Ключевые принципы**:
- Все типы известны на этапе компиляции.
- Неявные преобразования запрещены.
- Все выражения должны быть типо-согласованы.

## Литералы
Литералы типа `number`: \
Целочисленные литералы - последовательность цифр без десятичной точки (`0-9`). \
Знак (`+`, `-`) допускается в унарной форме (часть выражения), но не как часть литерала. \
EBNF:
```ebnf
int_literal = digit, { digit };
```

Литералы типа `decimal`: \
Представляют числа в десятичной форме с точкой. \
В литерале обязательно наличие десятичной точки и должна быть хотя бы одна цифра до и после точки. \
Знак `+` и `-` — не часть литерала. \
EBNF:
```ebnf
decimal_literal = digit, { digit }, ".", digit, { digit };
```

Литералы типа `text`: \
Строковые константы заключаются в одинарные кавычки `'...'`. В строковом литерале разрешены любые символы Unicode, кроме неэкранированной `'`. \
Для спецсимволов используются escape-последовательности (`"\'" | "\\" | "\n" | "\r" | "\t"`). \
EBNF
```ebnf
text_literal = "'", { character | escape_sequence }, "'";
escape_sequence = "\'" | "\\" | "\n" | "\r" | "\t";
```

Литералы типа `void`: \
`void` не имеет литералов, поскольку обозначает отсутствие возвращаемого значения.

## Операторы
### Арифметические операторы
|Оператор|Типы допустимых операндов        |Тип результата|Семантика            |
|--------|---------------------------------|--------------|---------------------|
|`+`     |`int`,`int` / `decimal`,`decimal`|тот же	      |сложение             |
|`-`     |`int`,`int` / `decimal`,`decimal`|тот же	      |вычитание            |
|`*`     |`int`,`int` / `decimal`,`decimal`|тот же	      |умножение            |
|`/`     |`int`,`int`	                   |`int`         |целочисленное деление|
|`/`     |`decimal`,`decimal`	           |`decimal`     |деление              |
|`%`     |`int`,`int`                      |`int`         |остаток              |
|`**`    |`int`,`int`	                   |`int`	      |степень              |
|`**`    |`decimal`,`decimal`	           |`decimal`     |степень              |

Строки не поддерживают оператор для конкатенации (`+`). Конкатенация осуществляется через функцию `concat(a, b)`.

### Операторы сравнения
Операторы `==` и != разрешены для всех типов, включая `text`.
ОстальныеL - `>`, `<`, `>=`, `<=` - применимы только к `int` и `decimal`.

Результат — `true/false`.

## Переменные
### Объявление
```
material x: int = 10;
fixed PI: decimal = 3.14159;
material s: text;
```
Объявление должно быть с явно указанным типом переменной. \
Если инициализация отсутствует, переменная получает неопределённое значение, использовать которое до присваивания запрещено.

### Присваивание
```
x = x + 1;
s = "hello";
```
Присваивание допускается только переменным `material`. \
Тип правой части обязан совпадать с объявленным типом.

## Преобразования типов
Так как язык Blueprint не поддерживает неявные преобразования, все преобразования выполняются через встроенные функции:

|Функция                                     |Описание          |
|--------------------------------------------|------------------|
|parseInt(t: text): int                      |Строка в int      |
|parseDecimal(t: text): decimal              |Строка в decimal  |
|toText(i: int): text                        |Число в строку    |
|toText(d: decimal): text                    |Decimal в строку  |
|toText(b: flag): text                       |Булево в строку   |
|length(s: text): int                        |Длина строки      |
|substring(s: text, pos: int, len: int): text|Подстрока         |
|concat(a: text, b: text): text              |Конкатенация строк|

Операции над типами не должны выполнять скрытых преобразований.
