# Семантика языка программирования Blueprint

## Области видимости
**Модель областей видимости** \
Язык использует лексические области видимости. \
Область видимости создаётся телом блока `{ … }`

**Жизненный цикл переменных** \
Локальные переменные существуют только в рамках своей области видимости. \
Запрещен доступ к переменной вне области её объявления.

**Замыкания** \
Замыкания не поддерживаются — функция не захватывает переменные извне. \
Функции могут использовать только свои параметры и свои локальные переменные.


## Уникальность имён
**Уникальность** \
Имя уникально в пределах одной области видимости

**Пространства имён** \
Переменные, функции и типы используют разные таблицы имён, поэтому переменная может называться так же, как функция.

**Сокрытие имён**
- Внутри блока можно объявить переменную с тем же именем, что и снаружи, тогда наружная скрывается.
- Можно скрыть имя встроенной функции.
- Нельзя скрыть имя встроенного типа данных.


## Параметры функций
**Способ передачи параметров** \
Все параметры передаются по значению.

**Изменение и сокрытие параметров**
Параметрам можно присвоить значение внутри функции и можно скрыть параметры локальной переменной .

**Совпадение количества аргументов** \
Число фактических параметров должно полностью совпадать с количеством формальных.

**Порядок вычисления аргументов** \
Параметры вычисляются слева направо.


## Рекурсия
Рекурсия допускается (Функция может вызывать сама себя).

**Взаимная рекурсия** \
Взаимная рекурсия поддерживается.

## Ветвления
### Условия
Условие должно быть только типа `bool` (выражение/оператор должен вернуть тип `bool`).

### Выполнение
Если условие истинно (значение типа `bool` - `true`), тогда выполняется тело if, иначе - тело else (если оно есть)


## Циклы
- Синтаксис: `cyclewhile(expr) { ... }`. \
  Перед каждой итерацией вычисляется `expr` (должен быть типа `bool`). \
  Если `true` — выполняется тело, затем снова проверка; если `false` — выход.
- Синтаксис: `cyclefor(init; cond; update) { ... }`.  
  Выполнение цикла:
    1. Выполнить `init` (может быть объявлением переменной или выражением).
    2. Вычислить `cond` (должен быть типа `bool`; если отсутствует — считается `true`).
    3. Если `cond` равно `false` — выйти из цикла.
    4. Выполнить тело.
    5. Выполнить `update` (если есть).
    6. Перейти к пункту 2.

**Break/Continue**
- `break` можно использовать только внутри циклов; завершает цикл.
- `continue` можно использовать только внутри циклов; переходит к выполнению `update` (в `cyclefor`) или к проверке условия (в `cyclewhile`).


## Прочие правила
**Левая часть присваивания** \
Присваивать можно только в:
- переменную
- параметр функции (копия).

Нельзя присваивать в выражения, литералы, вызовы функций и т.п.

**Инициализация переменных** \
Переменные должны быть инициализированы до использования. \
Использование неинициализированной переменной — ошибка.

**Константы (`fixed`)** \
- `fixed` - инициализируемая при объявлении, неизменяема далее. Попытка присвоить `fixed` - ошибка компиляции.
- `fixed` обязана иметь выражение инициализации в момент объявления.
