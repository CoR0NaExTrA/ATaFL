# Лексическая структура языка программирования Blueprint
## 1. Пример кода
```
{
    # Точка входа
    blueprint main() {
        material total: number = 0;
        material userInput: number;

        cyclewhile(raised) {
            dispatch("Введите число (0 для выхода): ");
            userInput = receive();
            check (userInput == 0) {
                break;
            }

            total = total + userInput;
        }

        dispatch("Сумма введённых чисел: ", total);
    }
}
```

## 2. Ключевые слова

Базовые конструкции:
|Слово    |Предназначение                      |
|---------|------------------------------------|
|material |Объявление переменной (let/var)     |
|fixed    |Объявление константы (const)        |
|receive  |Ввод данных                         |
|dispatch |Вывод данных                        |
|blueprint|Объявление функции (fun)            |
|yield    |Возврат значения из функции (return)|

Таблица типов данных:
|Слово      |Предназначение            |
|-----------|--------------------------|
|text       |Строка (string)           |
|number     |Целое число (int)         |
|decimal    |Вещественное число (float)|
|flag       |Логический тип (bool)     |
|raised     |Значение true             |
|lowered    |Значение false            |
|sequence   |Массивы (Array)           |

Ветвления и циклы:
|Слово     |Предназначение                   |
|----------|---------------------------------|
|check     |Условие/ветка (if)               |
|otherwise |Aльтернативная ветка (else)      |
|inspect   |Множественное ветвление (switch) |
|cyclewhile|Цикл while                       |
|cyclefor  |Цикл for                         |
|break     |Прерывание цикла                 |
|continue  |Переход к следующей итерации     |

Ключевые слова в Blueprint регистронезависимые. Варианты одного и того же ключевого слова `'material'`: `'material'`, `'MATerial'`, `'MATERIAL'` 

## 3. Идентификаторы
Идентификатор может:
1. Начинаться с буквы или нижнего подчёркивания "_"
2. Содержать буквы, арабские цифры 0, 1, ..., 9 и нижние подчёркивания "_"

## 4. Литералы
### 4.1. Литералы чисел
- Литерал целого числа состоит из арабских цифр: 0, 1, 2, ..., 9
- Литерал вещественного числа состоит из арабских цифр: 0, 1, 2, ..., 9 и плавающую точку между целой и дробной частью

### 4.2. Литералы строк
- Строки обрамляются в одиночные кавычки `'...'`
- Внутри допускаются любые символы, кроме необработанной одиночной кавычки `'`
- Может содеражать escape-последовательности:
    - Экранированная одиночная кавычка: `\'`
    - Экранированный обратный слэш: `\\`

## 5. Операторы
Язык поддерживает следующие операторы:
- сложение/унарный "+" - `+`
- вычитание/унарный "-" `-`
- умножение - `*`
- деление нацело - `/`
- деление с остатком - `%`
- возведение в степень - `**`
- строгое/нестрогое больше - `>`/`>=`
- строгое/нестрогое меньше - `<`/`<=`
- равенство - `==`
- неравенство - `!=`
- логическое И - `&&`
- логическое ИЛИ - `||`

## 6. Прочие лексемы
- `;` - используется как разделитель команд/инструкций
- `:` - используется как разделить идентификатора и типа данных
- `,` - используется как разделить в параметрах
- `=` - присвоение значений
- `(` и `)` - используются в функциях для вызова и параметров функций, также в выражениях
- `{` и `}` - используются для выделения блоков
