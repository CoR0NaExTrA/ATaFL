# Лексическая структура языка программирования MusicScript
## 1. Пример кода
```
TEMPO 120;
INSTRUMENT 'piano';

NOTE C4 1;
NOTE D4 1;
NOTE E4 2;

REPEAT 2 {
    NOTE G4 0.5;
    NOTE A4 0.5;
}

FUNC arpeggio(root) {
    NOTE root 0.5;
    NOTE root+4 0.5;
    NOTE root+7 0.5;
}

LET base = 60;
IF base > 50 {
    arpeggio(base);
} ELSE {
    NOTE base 1;
}
```

## 2. Ключевые слова

 
|Слово|Предназначение|
|-----|--------------|
|NOTE |Проигрывает ноту|
|LET  |Объявляет переменную и присваивает значение|
|REPEAT |Повторяет блок кода заданное кол-во раз|
|IF |Условное выполнение блока|
|ELSE|Альтернативный блок для IF|
|FUNC |Объявляет функцию|
|RETURN |Возвращает значение из функции|
|TEMPO |Устанавливает темп в ударах в минуту|
|INSTRUMENT|Выбирает инструмент|
|VOLUME |Устанавливает громкость|

Ключевые слова в MusicScript регистронезависимые. Варианты одного и того же ключевого слова `'REPEAT'`: `'REPEAT'`, `'repeat'`, `'rePEat'` 

## 3. Идентификаторы
Идентификатор может:
1. Начинаться с буквы или нижнего подчёркивания "_"
2. Содержать буквы, арабские цифры 0, 1, ..., 9 и нижние подчёркивания "_"

## 4. Литералы
### 4.1. Литералы чисел
- Литерал целого числа состоит из арабских цифр: 0, 1, 2, ..., 9
- Литерал действительного числа состоит из арабских цифр: 0, 1, 2, ..., 9 и точки между целой и дробной частью

### 4.2. Литералы строк
- Строки обрамляются в одиночные кавычки `'...'`
- Внутри допускаются любые символы, кроме необработанной одиночной кавычки `'`
- Может содеражать escape-последовательности:
    - Экранированная одиночная кавычка: `\'`
    - Экранированный обратный слэш: `\\`

## 5. Операторы
Язык поддерживает следующие операторы:
- сложение `+`
- вычитание `-`
- умножение 
- деление
- строгое/нестрогое больше `>`/`>=`
- строгое/нестрогое меньше `<`/`<=`
- равенство `==`
- неравенства `!=`
- логическое И `&&`
- логическое ИЛИ `||`

## 6. Прочие лексемы
- `;` - используется как разделитель команд/инструкций
- `,` - используется как разделить в параметрах
- `=` - присвоение значений
- `(` и `)` —  используются в функциях для прописывания параметров
- `{` и `}` - используются для выделения блоков
